BIOLOGY

生物学

生きものは、環境との関係の中で生きている。

4種類の文字で書かれた設計図から、一つひとつ違う生きものが生まれ、何十億年もかけて形を変えてきた。生物学は、生命のしくみと多様性、そしてその歴史である進化を扱う学問です。身近な生きものの観察と重ねながら、その地図を広げます。

01

生物学とは

生物学のあらゆることは、進化の光を当てなければ意味をなさない。
― ドブジャンスキー（要旨）

生物学は、生きものがどうできていて、どう働き、どう増え、どう変わってきたかを調べる学問です。どれほど小さな仕組みも、長い進化の中で選び残されてきた結果として見ると、なぜそうなっているのかが見えてきます。

扱うものは、小さい順に積み重なっています。

分子（DNA・タンパク質）→細胞→体→集団・生態系→進化（時間）
02

分野の地図

MOLECULAR BIOLOGY分子 ― 遺伝子とDNA

A・C・G・Tの4文字で書かれた遺伝情報が、タンパク質をつくり、体を形づくる。

問い：たった4文字から、なぜこれほど多様な生きものが生まれるのか遺伝子とDNAのノートへ →
CELL BIOLOGY細胞

すべての生きものの最小単位。神経細胞も、手の細胞と同じ膜と核とミトコンドリアを持つ、普通の細胞だった。

問い：同じ設計図から、なぜ違う種類の細胞ができるのか細胞のノートへ →
PHYSIOLOGY体 ― 生理学と脳

体がどう働くか。呼吸、循環、免疫、そして情報を統合して世界を組み立てる脳。

問い：体は、環境との関係の中でどう保たれているのか体 ― 生理学のノートへ →脳のノートへ →
ECOLOGY生態系

生きもの同士と、環境とのつながり。食べる・食べられる、すみ分け、生き残るための戦略。

問い：それぞれの生き方は、どんな環境への答えなのか生態系のノートへ →
EVOLUTION進化

変異と自然選択で、生きものは何世代もかけて形を変える。人類もその流れの中にいる。

問い：なぜ人間は、いまの体になったのか進化のノートへ →
BIOTECHNOLOGY生命を読む・書く

ゲノムの解読、ゲノム編集、iPS細胞。生命の設計図を読むだけでなく、書き換えられる時代になった。

問い：書き換えられるようになった生命と、どう向き合うのか生命を読む・書くのノートへ →
03

流れ

  1. 1735リンネの分類生きものに、属と種の名前を付けて整理する。
  2. 1859ダーウィン『種の起源』自然選択による進化。
  3. 1865メンデルの法則遺伝には、規則がある。
  4. 1953DNAの二重らせん遺伝情報の正体が分かる。
  5. 2003ヒトゲノムの解読完了人の設計図を、すべて読む。
  6. 2006・2012iPS細胞とゲノム編集細胞を巻き戻し、遺伝子を書き換える。

生命と人類の歴史を年表で見る →

04

自分の観察と問い

土の中こそが、本編だった

セミは何年も土の中で育ち、地上では繁殖だけに集中する。天敵の多い地上を避け、長い成長期を安全な場所に置くこと自体が、一つの生存戦略だった。うるさいと感じていた朝の声は、繁殖をかけた競争そのものだった。

土の中こそが、本編だった →セミの一生と生存戦略 →

摩耗するから、整う

野生の馬の蹄は誰も削らないのに伸びすぎない。長く歩く暮らしそのものが手入れになっている。体はそれだけで完結せず、環境との関係の中で保たれていた。文明化は、その手入れを環境から自分の手に引き取ることでもあった。

摩耗するから、整う →野生動物の爪と毛はなぜ手入れ不要なのか →

新皮質は、理性の脳ではなかった

新皮質が本能を支配する、という二層の図は正しくなかった。感情と理性は互いに影響し合い、脳は大きくなったというより、情報をつなぎ、まとめる力が高度になっていった。

新皮質は、理性の脳ではなかった →つなぐ力と、つながない力 →

景色ではなく、心を整える環境

自然の中にいると、心が落ち着く。人は長い進化の中で自然と共に生きてきたから、その感覚が体に残っているのかもしれない。

景色ではなく、心を整える環境 →
